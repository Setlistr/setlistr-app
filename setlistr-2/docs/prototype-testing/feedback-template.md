# Prototype test: feedback template

One copy per session. **Prototype:** the frozen version 5 (artifact version `1793636938-1136`, file fingerprint `1507016b928256ab`). Don't change it between sessions; write findings here, not in the prototype.

**Ground rules:**
- Record what people do and say, then what we think it means, kept separate.
- Quotes are word for word. Write "[paraphrase]" if you can't capture the exact words.
- Compliments ("love it", "really cool") go under Quotes only. **They are not adoption evidence.** Only a dated, specific commitment, or an action actually taken, counts.
- Don't explain the screen before they've tried it. If they ask, say "What would you expect it to do?"
